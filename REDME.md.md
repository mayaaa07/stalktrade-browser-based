# 📊 StalkTrade – Browser-based Stock Trading Simulation

StalkTrade is a **browser-based stock trading simulation platform** built with **Python (Flask), HTML, CSS, and JavaScript**.  
It allows users to simulate stock trading, track portfolios, add watchlists, and even interact with an **AI-powered assistant** for financial insights.  

---

## 🚀 Features
- 🔐 **User Authentication** – Secure login system for multiple users.  
- 📈 **Real-time Stock Data** – Fetches live stock prices and market trends.  
- 📊 **Portfolio Management** – Add, view, and manage stock holdings.  
- 👀 **Watchlist** – Track favorite stocks easily.  
- 🤖 **AI Assistant** – Ask trading-related queries using NLP-powered chatbot.  
- 📉 **Charts & Visualization** – Real-time price charts for better analysis.  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **Database:** SQLite (or any DB of choice)  
- **Libraries/Tools:** yFinance, Flask-SocketIO, ChatterBot, PowerBI (for analysis)
